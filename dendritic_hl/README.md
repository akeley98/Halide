# Dendritic Halide Harness -- Harness for agentic Halide scheduling

Harness that holds a "catalog" of Halide scheduling history.
This is a tree of C++ schedules stored on disk,
designed to be orthogonal to version control software.

* [idea.md](idea.md) for a conceptual overview of the harness and tool list (CLI commands)

* [impl.md](impl.md) for a sketch of the implementation
